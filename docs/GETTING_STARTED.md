# Getting started

1. Read the root [README](../README.md).  
2. Skim [ARCHITECTURE.md](ARCHITECTURE.md) (platform vs profile).  
3. Read the detailed [SCRIPTS.md](SCRIPTS.md).  
4. Example profile stub: [`../profiles/examples/grapevine-167k/`](../profiles/examples/grapevine-167k/).  
5. Stage **your** reference + sites + panel cache under `data/` (not shipped).  
6. `pip install -e ".[dev,web]"` then `grapeancestry --help`.  

Grapevine HTML demo walkthrough: [Xuzhen-Li/grapeancestry](https://github.com/Xuzhen-Li/grapeancestry).
