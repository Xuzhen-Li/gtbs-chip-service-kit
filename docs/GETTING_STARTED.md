# Getting started

1. Read the root README.
2. Check [REPO_LAYOUT.md](REPO_LAYOUT.md) to see what is included in this repository and what is not.
3. Install the package: [INSTALL.md](INSTALL.md).
4. Copy `templates/` to `profiles/examples/<chip_slug>/` and fill in `profile.yaml`.
5. Run `gtbs-kit validate-profile profiles/examples/<chip_slug>/profile.yaml` and `python -m pytest -q tests`.
6. For a full grapevine run, see https://github.com/Xuzhen-Li/grapeancestry
