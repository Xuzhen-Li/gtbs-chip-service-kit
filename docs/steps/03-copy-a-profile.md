# 3. Copy a profile for your chip

## Input

- `templates`.
- A folder name of your own, shown below as `your_chip`.
- `profiles/examples`.

## Do

```bash
cp -R templates profiles/examples/your_chip
```

## Get

- A profile directory under `profiles/examples`.
- `list-examples` prints any directory under `profiles/examples` that contains `profile.yaml`.
