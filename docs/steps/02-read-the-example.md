# 2. Read the example profile

Open `profiles/examples/grapevine_167k/profile.yaml`.

It records a label, `panel_n_sites: 167433`, and `coordinate_system: VS-1`. Paths for the site BED, sample info, and dosage cache are comments. Those files are not in this clone.

`walkthrough_url` points at [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry). That repo is the worked run. This file only names the panel.
