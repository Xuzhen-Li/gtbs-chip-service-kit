# Claims

Profiles declare which results are **decision-grade** vs **exploratory**.

Example pattern (grapevine 167K):

- Decision-grade today: one named trait GS score (e.g. colour OIV 225).  
- Exploratory: other GS traits, unphased sex proxies, selection overlays, f3/f4.  
- Query genotype on a panel LocusZoom is an **overlay**, not proof that the sample was selected.

Each profile should ship a short `CLAIMS.md` (or section in its README) so customers do not over-claim.
