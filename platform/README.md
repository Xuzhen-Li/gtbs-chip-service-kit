# platform/

Interface notes. The subfolders (`pipeline/`, `report/`, `viz/`, `cloud/`) match the interfaces in `gtbs_kit.spi`.
The Python code lives in `gtbs_kit.spi`, not in a package named `platform`, so it does not clash with the standard-library `platform` module.

See [docs/REPO_LAYOUT.md](../docs/REPO_LAYOUT.md).
